# 旅行ルートトラッカー

旅行中の位置情報とルートを記録・管理するPWA（Progressive Web App）です。

## 主な機能

- 📍 **リアルタイム位置追跡**: GPS を使用して移動ルートを自動記録
- 🗺️ **地図表示**: OpenStreetMap を使用したインタラクティブな地図
- 📝 **訪問地点の記録**: 訪れた場所に名前とメモを付けて保存
- 📊 **統計情報**: 移動距離、時間、速度などの統計データを表示
- 💾 **データエクスポート**: GPX 形式でデータをエクスポート（他の地図アプリでも利用可能）
- 📱 **PWA対応**: オフラインでも動作し、スマホのホーム画面に追加可能

## セットアップ

### 方法1: インターネット公開（推奨・外出先でも使用可能）

GitHub Pagesで無料ホスティングすれば、インターネット経由でどこからでもアクセスできます。

詳しい手順は [DEPLOY.md](DEPLOY.md) をご覧ください。

**メリット:**
- 外出先のスマホから直接アクセス可能
- PC不要でスマホ単体で使用可能
- HTTPSで安全に動作
- 完全無料

### 方法2: ローカルで試す（開発・テスト用）

#### 必要な環境
- Python 3.x（ほとんどのPCに標準でインストール済み）

#### 起動方法

**Windows:** `start.bat` をダブルクリック

**Mac/Linux:** 
```bash
bash start.sh
```

開発サーバーが起動したら、ブラウザで `http://localhost:3000` にアクセス。

#### スマホからアクセス（同じWi-Fi内のみ）

1. PCとスマホを同じWi-Fiネットワークに接続
2. PCのIPアドレスを確認（例: 192.168.1.100）
3. スマホのブラウザで `http://[PCのIPアドレス]:3000` にアクセス
   例: `http://192.168.1.100:3000`

**注意:** この方法ではPCと同じWi-Fi内でしか使用できません。外出先で使用するには方法1を選択してください。

## 使い方

### 1. 位置情報の許可
初回起動時に位置情報へのアクセス許可を求められます。「許可」を選択してください。

### 2. ルートの記録
1. **記録開始**ボタンをタップして記録を開始
2. 移動するとリアルタイムでルートが地図上に描画されます
3. **記録停止**ボタンで記録を停止

### 3. 地点の追加
1. **地点追加**ボタンをタップ
2. 地点名とメモを入力
3. **保存**ボタンで地点を登録

### 4. 統計の確認
**統計表示**ボタンをタップすると、以下の情報が表示されます：
- 総移動距離
- 記録時間
- 訪問地点数
- 平均速度
- 訪問地点のリスト

### 5. データのエクスポート
**エクスポート**ボタンをタップすると、GPX形式でルートデータをダウンロードできます。
このファイルは Google Earth、Garmin、Strava などの地図アプリで開くことができます。

## スマホのホーム画面に追加

### Android (Chrome)
1. ブラウザのメニュー（⋮）を開く
2. 「ホーム画面に追加」を選択
3. アプリ名を確認して「追加」をタップ

### iOS (Safari)
1. 共有ボタン（□↑）をタップ
2. 「ホーム画面に追加」を選択
3. アプリ名を確認して「追加」をタップ

## 注意事項

- 位置情報の記録にはバッテリーを消費します
- 長時間の記録を行う場合は充電器やモバイルバッテリーの使用を推奨します
- データはブラウザのローカルストレージに保存されます
- ブラウザのデータを削除すると記録も削除されるため、重要なデータは定期的にエクスポートしてください

## トラブルシューティング

### 位置情報が取得できない
- スマホの位置情報設定がオンになっているか確認
- ブラウザに位置情報のアクセス許可を与えているか確認
- HTTPS接続または localhost でアクセスしているか確認（HTTP では位置情報が取得できません）

### 地図が表示されない
- インターネット接続を確認
- ブラウザのキャッシュをクリア
